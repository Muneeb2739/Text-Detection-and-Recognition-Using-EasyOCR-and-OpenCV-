# Image-Based Text Detection and Recognition Using EasyOCR

## Overview
This project is an OCR (Optical Character Recognition) system that detects and recognizes text from images using EasyOCR and OpenCV.

## Technologies
- Python
- OpenCV
- EasyOCR
- Matplotlib

## How It Works
1. Loads an image using OpenCV.
2. EasyOCR detects and recognizes the text.
3. Draws bounding boxes around detected text.
4. Displays the processed image.
